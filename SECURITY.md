# Security Policy

Do not publish exploit details, API keys, private pitch decks, confidential company data, founder personal information, or unredacted research exports in public issues or pull requests.

Use GitHub's Security tab and **Report a vulnerability** flow when private vulnerability reporting is enabled. If unavailable, contact the repository owner privately through their GitHub profile and request a secure route. Do not disclose details publicly while arranging contact.

Include the affected version/commit, exact component, synthetic reproduction steps, demonstrated impact, and redacted logs. Never attach private investment materials or live credentials.

Venture Scout is an evidence organization and prioritization aid. It is not investment advice, a valuation service, or a guarantee of returns. Treat imported source data and model-generated summaries as untrusted until verified.
